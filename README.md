# OvenTrio-FFmpeg

Custom FFmpeg and FFplay builds for **Oven Trio Studio**.

This repository distributes customized Windows binaries based on the official FFmpeg project, including a modified FFplay player with additional playback controls and seamless transitions between media files.

## Features

- Custom-built FFmpeg tools for Windows x64.
- Modified FFplay with additional playback controls.
- Seamless transitions between media files without recreating the playback window.
- Support for media formats and codecs enabled in each build.
- Versioned ZIP archives for convenient distribution and updates.

## Downloads

Download the required Windows build from the repository's **Releases** section.

Each release should include its version number, build configuration, supported components, and archive checksum.

## Build Information

Builds are based on the official FFmpeg source code, with project-specific modifications.

- Upstream project: https://ffmpeg.org/
- Official source code: https://git.ffmpeg.org/ffmpeg.git
- Target platform: Windows x64
- Distribution format: ZIP archives

Build configurations and included libraries may differ between releases. Refer to the notes accompanying each release for exact details.

## Compatibility

These builds are intended primarily for use with Oven Trio Studio. Compatibility with other applications is not guaranteed.
